# ASK Sathvik

Personal website focused on longevity, healthspan, intelligence, and evidence.

**Website:** https://sathvikask0.github.io/

## Edit the site

- `index.html`: page content, research projects, essays, experience, and metadata.
- `style.css`: layout, typography, colors, and responsive styles.
- `script.js`: animated conceptual network and footer year.

No dependencies or build step are required. To preview locally:

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. Push changes to `main` to update GitHub Pages automatically. GitHub Pages publishes the repository root; `.nojekyll` keeps it a plain static site.

Research descriptions link to their source repositories. Health essays are personal reading notes. Career and education information was supplied by Sathvik.
